# 封面机 · Cover Machine

一套给 WorkBuddy 用的**图书封面生成技能**：把"每张封面都要人工挑文案"改成"一次定好、之后自动循环出图"。

输出规格：**1080 × 1440 PNG**，横竖比 3:4，适合小红书 / 抖音图文 / 视频封面。

---

## 它解决什么问题

旧流程：每做一张封面 → AI 出一张 4 组的文案表 → 人选 → 才渲染。**每张都要停一次人工决策。**

新流程（本仓库）：

| 环节 | 做法 |
|------|------|
| 同一本书**首次**出现 | 一次出 **15 套完整文案**（主标题三行 + 副标题 + 左标签 + 右标签 + 右下角标签），只出表不渲染 |
| 人选 | 至少选 5 套，多选无妨（5~8 常见），报编号即可 |
| 落盘 | 存进 `presets.json`，含 5~N 套文案 + 轮换指针 + 已用色记录 |
| 之后每集 | 直接取指针那套 → 自动配色（避开最近 3 色）→ 出图 → 指针 +1 循环 |
| 回退 | 说「回到手动模式」立刻退回逐张确认；说「继续用封面机」切回 |

省下来的是**每集那一次等待**，不是渲染时间。

## 安装

**方式一：命令行**

```bash
git clone <本仓库地址> cover-machine
cd cover-machine
bash install.sh
```

**方式二：手动**

把 `skills/` 下的 `封面机`、`做封面` 两个文件夹整个复制到：

```
%USERPROFILE%\.workbuddy\skills\        （Windows）
~/.workbuddy/skills/                    （macOS / Linux）
```

装完**重启 WorkBuddy**，技能才会加载。

---

## 换电脑 / 交给别的 AI 智能体

把仓库链接丢给新电脑上的智能体，附带这句话：

> 克隆这个仓库，跑 `bash install.sh`，它会把「封面机」和「做封面」两个技能装到 `~/.workbuddy/skills/`。装完我来出封面，你按 `skills/封面机/SKILL.md` 的流程走：新书先给我 15 套文案让我选，之后按预设循环自动出图。

智能体读完 `skills/封面机/SKILL.md` 就能完整复现能力，不依赖任何历史对话。

## 使用方式

**出一张封面**（首次遇到这本书）：

```
《书名》 D:\某目录\书名-1-2-3
```

→ 得到 15 套文案表 → 回 `1/5/8/12/14` → 立刻出第 1 套。

**之后每集**：

```
《书名》 D:\某目录\书名-1-2-3-4
```

→ 不再问，直接出第 2 套，换个颜色。

**局部调整**：`3 号换掉`、`从第 2 套开始`、`这本以后都走手动`。

**全局回退**：`回到手动模式` / `继续用封面机`。

## 硬规则（不要改坏）

模板二（最常用）的字数约束，写文案时必须逐行点数：

| 字段 | 约束 |
|------|------|
| 主标题第 1/2/3 行 | 各 **≤5 字**、≥2 字，**三行字数不能全相同** |
| 副标题 | **4~5 字** |
| 左侧标签 / 右侧标签 | 各**恰好 4 字** |
| 右下角标签 | **恰好 2 个汉字**，按品类固定（数学/健身/技术/芯片/效率/机械…），一次定死不改 |

模板一、模板三的约束见 `skills/做封面/SKILL.md` §五。

## presets.json 说明

```json
{
  "books": {
    "书名": {
      "status": "preset",        // preset=已定套；legacy=只有历史记录
      "pointer": 2,              // 下一张用 presets[2]
      "presets": [ { "m": ["三行","主标题","示例"], "sub": "副标题", "left": "…", "right": "…", "tag": "数学" } ],
      "used":   [ { "date": "…", "color": "#3730A3", "dir": "目录名" } ]
    }
  }
}
```

- `pointer` 在 `0 ~ presets.length-1` 之间循环，**套数不固定 5，选几个存几个**。
- `used` 只增不删，配色避让和标题去重都靠它。
- 换电脑时把这个文件一起带走，进度能接上。

## 已知限制

- 渲染依赖 **Chrome**（headless 截图）与 **Python**（文件复制），Windows 上 HTML 必须写到纯英文临时路径，否则 `file:///` 会渲染空白页。
- 技能按 Windows 路径编写，macOS / Linux 需要改 `install.sh` 与渲染命令里的路径写法。
- 模板是固定版式，只能换文字和配色，不能换布局。
