## 替换方法

所有替换为简单 sed 字符串替换。模板内的占位符文本即为替换目标：

```
一本书看懂  → M1
芯片通识课  → M2
从沙到硅    → M3
芯片入门一本搞定 → B1
好书分享    → T2
值得收藏    → T3
（技术）    → B6
#0ea5e9     → C1（如需要）
```

⚠️ 题目色改动时需同时替换 `fill:#XXXXXX` 和 `stroke:#XXXXXX`（cls-8 和 cls-9 分别用 fill 和 stroke）。

⚠️ 左下英文（cls-13）必须保持 font-weight:300（如模板中缺失则补上），确保渲染为细体。
