## 替换方法

sed 逐条替换：

```
8个很棒的    → M1
VUE          → M2
开发技巧哈哈  → M3
五字以内啊    → B1
自由发挥      → T2（第一个）
自由发挥      → T3（第二个，区分位置）
（收藏）      → B6
#39afbc       → C1+C2（如换色）
```

⚠️ 渐变换色需同时替换 `<linearGradient>` 内 11 个 stop-color + cls-19 fill。

⚠️ cls-11 必须保持 font-weight:300，确保左下英文渲染为细体。
