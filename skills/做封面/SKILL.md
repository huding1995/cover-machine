# 做封面

> 🔁 **批量出片走 [`封面机`](../封面机/SKILL.md)**：同一本书首次出现时一次出 15 套文案，选定 5 套后按 1→5 循环自动出图、自动换色，不再逐集等确认。只有在用户说「回到手动模式」时才回到本文件的逐张确认流程。

## 一、触发与总流程

1. 用户说「做封面」「/做封面」「做个封面」。
2. 只需要两样信息：**书名**、**PNG 保存到哪个文件夹**。用户已经给了就直接开工，不要再问。
3. 自动完成：
   - 判断书的类型和气质 → 选模板
   - 写 4 组文案 → **主标题先拆书名（见 §四），不是从口播里摘句子** → **逐行点数（模板二每行 ≤5 字）** → 超字的当场重写 → 才出选项表
   - 定一个主色（不查历史、不扫目录，自己按气质定）
   - 用户选定后：sed 替换 SVG → Chrome 无头渲染 PNG → 复制到目标目录 → 播放提示音
4. 完成后报告：模板、主标题、副标题、左侧标签、右侧标签、右下角标签、配色、品牌名、保存路径。
5. **PNG 渲染完成后禁止验证**：不要用看图工具检查、不要用 PIL 验像素、不要打开浏览器。直接报路径。用户觉得有问题会自己说。

## 二、模板选择

| 书的特点 | 推荐模板 | 原因 |
|----------|---------|------|
| 通识课、入门书、技能教程、Step-by-Step、学习路径 | 模板二 | 渐变背景+下划线+步骤条，万能默认，适合大多数书 |
| 经典名著、严肃学术、教材 | 模板一 | 三行主标题+椭圆弧线，简洁有力，传达权威感 |
| 年轻化、榜单、快消类、视觉冲击力强的 | 模板三 | 十字交叉+大色块+三按钮，杂志风抢眼 |

**模板二是万能首选**；模板一适合严肃学术/经典/教材；模板三适合需要"炸裂"视觉的快消书。

## 三、配色原则

根据书的**气质和主题**做审美判断，不要查表：
- 科技/AI/编程/芯片 → 冷调蓝系
- 历史/战争/权谋 → 厚重红棕
- 心理/自我成长/疗愈 → 温暖橙/珊瑚
- 财富/商业 → 饱满金/墨绿
- 数学/逻辑 → 清冷深蓝/靛蓝
- 文学/艺术 → 表现紫/品红
- 健身/运动 → 高饱和橙红/活力色
- 教辅/学生书 → 明快蓝、橙、绿

要求：**高饱和亮色，一次只用一个主色**。

> ⚠️ **文字颜色不要动**。三套模板的字色已经在 SVG 里定好了：模板一/二的主标题、标签是近黑 `#000201`（靠浅色渐变做对比），模板三标题是黑、深色条/卡片上的字是白。references 规范表里写的「#fff」只对深色底上的字段成立。**换配色只换背景块/线条/渐变，不要给标题加 fill**。


## 四、文案选项表（硬规则）

**A 固定为「都不行，重写」**。B~E 才是实际文案。

**每个字段必须带固定编号，表头固定写成：**

| 选项 | **1** 主标题（三行） | **2** 副标题 | **3** 左侧标签 | **4** 右侧标签 | **5** 右下角标签 |
|------|---------------------|-------------|---------------|---------------|-----------------|
| **A** | 都不行，重写 | — | — | — | — |
| **B** | …… | …… | …… | …… | …… |
| **C** | …… | …… | …… | …… | …… |
| **D** | …… | …… | …… | …… | …… |
| **E** | …… | …… | …… | …… | …… |

编号含义（固定不变）：
- **1 = 主标题**（三行，单元格内用 `<br>` 分行）
- **2 = 副标题**
- **3 = 左侧标签**
- **4 = 右侧标签**
- **5 = 右下角标签**

### 🔴 主标题（1）怎么写：锚定书名，不锚定文案碎句

封面上最大的三行字，作用是**让人在两秒内知道这是本什么书**，不是复述视频里的一句话。

1. **先找书名。** 书名在用户给的那段信息里——有时是书名本身，有时是视频/字幕里念出来的（如字幕"这本肌肉力量训练彩色图谱早就讲全了"→ 书名=肌肉力量训练彩色图谱）。**书名就是主标题的第一素材。**
2. **把书名拆成三行**，最长的一行给书名主体。例：《肌肉力量训练彩色图谱》→ `肌肉力量 / 训练图谱 / 彩色版`。连读要像书名。
3. 想加钩子可以，但**最多占一行，且必须自带主语**：`肌肉怎么练` ✓ ／ `动作细节全在图上` ✗（什么动作？什么图？）。
4. **禁止**从口播文案里摘一句顺口的碎句子当主标题。检验方法：把三行单独念给没看过视频的人听，他得能说出"这是讲 XX 的书"；说不出来就是废稿。

### 🔴 已定品类字段不参与选项

右下角标签（5）这类字段，一旦书的品类确定就是固定值——健身书就是 `（健身）`、心理书就是 `（心理）`。**直接填死，不要放进选项里让人挑，也不要换着花样给它起名。** 同理：系列里已经固定的模板、品牌名，都不用再问。

用法：用户可以回 `B`（整组）、`B 的 1 换成 XXX`、`B 的 1、5 换成 XXX、YYY`、`用 C 的 1、2 + D 的 3、4、5`、`A`（整组重写）。

⚠️ 字段名统一叫「左侧标签 / 右侧标签」，**不要写成「标签左 / 标签右」**，那是 SVG 内部字段名，给用户看不合适。

## 五、字数硬约束（逐字点数，超一个字都不行）

> 🔴 **点数必须发生在写选项表的时候，不是渲染前。** 任何一行超字的候选，当场毙掉重写，不许写进表里让用户挑——用户挑中了才发现超字，等于白挑一轮。
>
> 🔴 **模板二主标题 = ≤5 字/行，不是 6 字。** 三行各自 ≤5，且三行字数不能全相同。这条被明确要求过，再犯就是低级错误。

### 模板一

| 字段 | 约束 |
|------|------|
| M1 主标题第1行 | ≤5字，且 ≥2字 |
| M2 主标题第2行 | ≤5字，且 ≥2字 |
| M3 主标题第3行 | ≤5字，且 ≥2字 |
| B1 副标题 | ≤8字 |
| T2 左侧标签 | **恰好4字** |
| T3 右侧标签 | **恰好4字** |
| B6 右下角标签 | **恰好2个汉字** |

补充：M1/M2/M3 三行**不能全部相同字数**（两行相同、一行不同可以）。

### 模板二

| 字段 | 约束 |
|------|------|
| M1 主标题第1行 | **≤5字**，且 ≥2字 |
| M2 主标题第2行 | **≤5字**，且 ≥2字 |
| M3 主标题第3行 | **≤5字**，且 ≥2字 |
| B1 副标题 | **4~5字** |
| T2 左侧标签 | **恰好4字** |
| T3 右侧标签 | **恰好4字** |
| B6 右下角标签 | **恰好2个汉字** |

补充：M1/M2/M3 三行**不能全部相同字数**。

> ⚠️ 模板二主标题上限是 **5 字**，不是 6 字。技术上 6 字画得下（149.1px×6 + 左边距 41 = 936，右边还空 144px，标题行右侧无任何元素），但 6 字那行会明显比 3、4 字的两行宽一截，三行看起来像碎片。**做版面判断时不要用"能不能放下"，用"三行看着齐不齐"。** 模板二自带的 6 字占位符「开发技巧哈哈」只是旧占位，不代表上限。

### 模板三

| 字段 | 约束 |
|------|------|
| M2 十字横 | 恰好2字 |
| M3 十字竖 | 恰好4字 |
| M1 十字下方 | ≤11字 |
| S1/S2 副标题两行 | 各≤13字 |
| BTN1/BTN2/BTN3 三个按钮 | **各恰好4字** |
| BOTTOM 标注 | 4字 |
| TBL 四格 | 每格≤6字，**四格内容必须全部不同** |

⚠️ 渲染前必须逐字点数，这是硬红线。若用户给的词超字数，先说明再调整（例如把 5 字的「有理数运算」改成 4 字的「四则运算」）。

## 九、系列续集：不查历史，每次现写

**不做任何历史比对。** 不遍历目录、不打开历史封面图、不读任何台账/记录表。上一集用过什么颜色、写过什么文案，都跟这一集无关。

理由：扫盘和查表都要花时间和 token，收益却很低——用户会自己说"这个颜色跟上集撞了"。

每次的做法：

1. 只依据**用户这一次给的信息**（书名、目录名、视频/字幕内容、他口述的主题）写一组全新文案，出 B~E 四组。
2. 主色自己按书的气质定，一条原则：**别用上一轮最顺手的暖橙/正红**（这两类最容易连着撞），优先冷色、绿、黄、深色系。
3. 用户开口说"跟上一集一样"就沿用，说"换色"就换，不需要我去猜。
4. 系列里的书名/集数已经在路径里，只看路径字面，不再去盘。

一句话：**写字靠这一集的材料，配色靠这一眼的判断，不翻旧账。**

## 十、PNG 渲染命令（可移植 + 防竞态）

硬约束：
- HTML **必须**写到纯英文路径（Windows 临时目录），否则 Chrome 的 `file:///` 遇到中文路径会渲染空白页。
- Chrome 的 `--user-data-dir` 每次用**唯一目录**，避免上一次进程占用导致截图不生成。
- Chrome 命令后加 `sleep 1`，防止 PNG 还没写完就去复制（踩过坑）。
- 复制用 PowerShell `Copy-Item`，不依赖 Python。

```bash
# 0. 临时目录（每台 Windows 都有 LOCALAPPDATA）
TMPDIR="$(cygpath -m "${LOCALAPPDATA}/Temp")"

# 1. 生成 HTML
cat > "${TMPDIR}/cover_t2.html" << HTMLEOF
<!DOCTYPE html><html><head><meta charset="utf-8"><style>body{margin:0;background:#fff;}svg{width:1080px;height:1440px;display:block;}</style></head><body>${SVG}</body></html>
HTMLEOF

# 2. 自动探测 Chrome（找不到就手动改这一行）
CHROME=""
for c in \
  "C:/Program Files/Google/Chrome/Application/chrome.exe" \
  "C:/Program Files (x86)/Google/Chrome/Application/chrome.exe" \
  "$(cygpath -m "$LOCALAPPDATA" 2>/dev/null)/Google/Chrome/Application/chrome.exe"; do
  [ -f "$c" ] && CHROME="$c" && break
done
[ -z "$CHROME" ] && echo "找不到 Chrome，请手动修改 CHROME 路径" && exit 1

# 3. 截图（唯一 profile + sleep 1）
CTMP="${TMPDIR}/cover_profile_$(date +%s)"
"${CHROME}" --user-data-dir="${CTMP}" --headless=new --disable-gpu --no-sandbox \
  --disable-extensions \
  --screenshot="${TMPDIR}\\cover_t2.png" --window-size=1080,1440 \
  "file:///${TMPDIR}/cover_t2.html"
sleep 1

# 4. 复制到目标目录（中文路径）
#    本机安全策略禁止从 bash 调 powershell，用 python 复制最稳：
python -c "import shutil,sys; shutil.copy2(sys.argv[1], sys.argv[2])" "${TMPDIR}/cover_t2.png" "${OUTPUT}/封面_模板2.png"
#    （若环境允许，也可用 PowerShell 工具直接执行 Copy-Item -LiteralPath ... -Force）

# 5. 清理
rm -f "${TMPDIR}/cover_t2.html" "${TMPDIR}/cover_t2.png"

# 6. 提示音（可选）
NOTIFY="$(cygpath -m "${USERPROFILE}")/notify_me.ps1"
[ -f "$NOTIFY" ] && powershell -ExecutionPolicy Bypass -File "$NOTIFY"
```

> 上面的模板编号 `2`/`封面_模板2.png` 按实际模板改成 1/2/3。
