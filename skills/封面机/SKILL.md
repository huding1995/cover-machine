# 封面机

## 〇、两条铁律（最高优先级）

1. **默认走预设模式。** 用户没明确说「回到手动模式」，就一直按本技能执行——**不要每集出选项表去问**，直接出图。
2. **回退开关。** 用户说「回到手动模式」「改回手动」「不要预设了」「还是老的来吧」→ **立刻停用本技能**，改用 `做封面` 技能原流程（每集出 B~E 四组选项表、等确认、再渲染）。直到用户明确说「继续用封面机」才切回来。

## 一、判断这本书是不是第一次进来

**主键 = 书名，不是目录名。** 同一本书在不同目录下（如「读书狼肌肉新1-2-3」与「超级读书狼-肌肉图谱1」）算同一本书，共享预设。

开工前先读 `presets.json`：

| 情况 | 走哪个流程 |
|------|-----------|
| `books` 里没有这个书名 | **首次流程**（§二） |
| 有，但 `status: "legacy"`（只留了历史记录、没定过 5 套） | **首次流程**，出 15 套时先扣掉 `used` 里已用过的标题 |
| 有，`status: "preset"` 且 `presets` 有 5 套 | **日常流程**（§三） |

## 二、首次流程：一次出 15 套

1. 只依据书名（有字幕/目录名可参考，但主标题必须锚定书名）写 **15 套完整文案**，每套 =
   - 主标题 3 行
   - 副标题
   - 左侧标签
   - 右侧标签
   - 右下角标签（按品类固定，如（机械）（数学）（健身）（技术）（芯片）（效率））—— **必须单列一列写进表格，不许省**
2. **字数硬约束**（等同 `做封面` §五 模板二，逐字点数，超一个字当场重写）：
   - 主标题每行 **≤5 字**且 ≥2 字，三行字数**不能全相同**
   - 副标题 **4~5 字**
   - 左右标签 **恰好 4 字**
   - 右下角 **恰好 2 个汉字**
3. **15 套必须真的不同**：每套的切入角度能说出区别，不许只换一两个字凑数。`used` 里出现过的标题不再给。
4. 一次性出表（编号 **01~15**，方便用户只报数字），**表格必须含「右下角标签」列**，该列首次就按品类定死（机械类→（机械）、健身→（健身）、数学→（数学）、芯片→（芯片）、效率→（效率）、其它技术→（技术）），选定后永不改动。末尾报一个自定主色建议。**只出表，不渲染，等用户选。**
5. 用户报编号，**至少 5 个、可以更多**（常见 5~8 个；可能附「第 7 套副标题改成 XX」这类微调）→ 按他报的顺序组装 `presets[0..N-1]`，写入 `presets.json`（`status` 改 `preset`，`pointer` 归 0）。**套数不写死 5，报几个存几个。**
6. 写完**立刻按 §三 出第一张**（pointer = 0），不再问一遍。

## 三、日常流程：不问，直接出

1. 读 `presets.json`，取 `presets[pointer]` 那一套文案。
2. **配色自己定**：按书的气质挑一个高饱和主色，**必须避开该书 `used` 里最近 3 个颜色**（色相接近的也算撞，深浅不同不算过关）。
3. 按 `做封面` 技能 **§七**（模板二 11 阶渐变 + 文本 sed 替换）和 **§十**（Chrome 无头渲染 + python 复制到中文目录）执行，一路出到目标目录。
4. 交付：报字段表 + 保存路径，一两句话，别啰嗦。
5. **写回 `presets.json`**：`used` 追加本次（日期 / 文案四项 / 颜色 / 目录），`pointer = (pointer + 1) % presets.length` —— 在已存的那 N 套里循环，**不固定 5**。
6. 中间不播检查点音（没有需要用户拍板的事），只在完成时播 done。

## 四、随时可以插手的三种情况

| 用户说 | 我做什么 |
|--------|---------|
| 「3 号换掉」/「第 2 套不好」 | 出 3~5 套替换候选，用户挑中后只替换 `presets[2]`，其他四套和 pointer 位置都不动 |
| 「从第 2 套开始」 | 把 `pointer` 改成 1，下一张就用第 2 套 |
| 「这本以后都走手动」 | 该书单独退回逐张确认，其他书不受影响 |

## 五、presets.json 结构

位置：`C:\Users\Administrator\.workbuddy\skills\封面机\presets.json`

```json
{
  "version": 1,
  "updated": "YYYY-MM-DD",
  "books": {
    "书名": {
      "status": "legacy | preset",
      "template": 2,
      "brand": "小胡爱读书",
      "pointer": 0,
      "presets": [
        { "id": 1, "m": ["三行", "主标题", "示例"], "sub": "副标题", "left": "左侧标签", "right": "右侧标签", "tag": "数学" }
      ],
      "used": [
        { "date": "YYYY-MM-DD", "m": ["…"], "sub": "…", "left": "…", "right": "…", "color": "#RRGGBB", "dir": "D:/…" }
      ]
    }
  }
}
```

- `status: legacy` = 只在 `used` 里留了历史，没定过预设；下次进来仍要走首次流程。
- `presets` **至少 5 条、允许任意条数（N ≥ 5）**，`pointer` 在 `0 ~ N-1` 之间循环。用户报 8 个就存 8 条。
- 每本 `presets` 里的 `tag`（右下角标签）**全书统一、写进去就不改**。
- `used` 只增不删，配色避让和标题去重都靠它，也是查账依据。

## 六、不要做的事

- ❌ 不要每集重新写 15 套——只在**该书首次**出一次。
- ❌ 不要在预设模式里出 B~E 选项表。
- ❌ 不要把模板 SVG 的渐变值、sed 命令抄进本技能——一律照 `做封面` 的 §七 / §十 执行，避免两处规则失同步。
- ❌ 不要因为 `used` 里已经有记录就跳过首次流程；`legacy` 书第一次进预设模式照样出 15 套（扣掉已用标题）。
- ❌ 不要用同一套文案连出两张（pointer 只管往前走，不走回头路）。
- ❌ 不要把预设套数写死成 5 —— 用户报几个就存几个，循环按 `presets.length`。
- ❌ 不要在 15 套表格里省掉「右下角标签」列，也不要中途换这个标签。
